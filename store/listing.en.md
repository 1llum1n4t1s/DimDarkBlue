# Store listing (English, draft)

## Name

Dim Dark Blue

## Short description (max 132 characters; same as manifest.json)

A calm dark navy blue theme for Chrome with soft, low-glare contrast. Easy on the eyes for late-night browsing.

## Detailed description

Dim Dark Blue gives Chrome's tabs, toolbar, address bar and New Tab page a calm dark navy look.

- A navy base that is softer than pure black, comfortable for long sessions
- Text colors chosen for readability, with sufficient contrast on the main text and background pairs
- A colors-only theme: no images, no permissions, and no scripts

You can reset the theme at any time from Chrome's Settings > Appearance.

This is an unofficial theme made by an individual and is not affiliated with any service or company.
